# SHARED_REFERENCE_OWNERSHIP

## Purpose

Defines ownership of shared reference catalogs across OM–HR–PS–Culture.

Each shared reference must have ONE authoritative owner.

---

## Ownership Matrix

| Reference | Owner |
|---|---|
| skills catalog | HR |
| functions catalog | Bridge / PS |
| worker types | HR |
| approval statuses | Bridge / Governance |
| job families | OM |
| position classes | OM |
| value categories | Culture Values |
| behavior scales | Culture Values |
| vendor clauses | Culture Values |

---

## Rules

- single source of truth per reference
- consumers must not redefine
- changes must be governed
- high-impact references must be auditable

---

## Status

Governance-defined before runtime implementation

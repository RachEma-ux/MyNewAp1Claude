# MODULE_RISKS — Culture Values

## Purpose

Defines the risk register for the Culture Values domain.

Culture Values is vulnerable to behavior-governance failure rather than structural failure.

---

## Key Risks

### R1 — Symbolic Values
Values defined but not operationalized.

### R2 — Subculture Drift
Departments create contradictory behaviors.

### R3 — HR Overreach
HR defines values instead of consuming them.

### R4 — PM Overreach
Projects define their own culture rules.

### R5 — Vendor Misalignment
Partners not aligned with values.

### R6 — Audit Gaps
No traceability for changes.

### R7 — Inconsistent Evaluation
Different scoring models across teams.

### R8 — Ownership Ambiguity
No clear value owner.

### R9 — Policy Drift
Values not linked to enforceable policy.

---

## Mitigation

- central governance
- audit enforcement
- periodic checks
- policy linkage

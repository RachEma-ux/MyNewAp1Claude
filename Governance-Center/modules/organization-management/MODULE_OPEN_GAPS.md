# MODULE_OPEN_GAPS — Organization Management

## Purpose

Documents the current gaps for OM governance and implementation.

## Gaps

### G1 — No runtime module yet
OM exists only as governance definition.

### G2 — HR currently hosts OM-like capabilities
- organization structure
- job architecture
- position management

### G3 — No authority-chain enforcement yet
Approval chain is not yet derived from OM.

### G4 — No bridge integration
- resource_request not implemented
- resource_assignment not implemented

### G5 — No audit implementation
Audit model defined but not implemented

### G6 — No UI surfaces for OM
No Position / Job / Org Unit dedicated UI under OM module

### G7 — No migration strategy
No defined plan to move structure from HR to OM

## Status

All gaps expected at this stage.

OM is intentionally defined before implementation.

## Key Technical Decisions

### savedId State Pattern
Problem: After saving a new workflow, the app would navigate away from the Designer.
Solution: Track `savedId` in React state instead of URL changes. The editId is derived as:
  `const editId = savedId ?? (urlEditMode ? urlId : null);`
This avoids any URL/navigation change that would cause wouter to re-render the page.
Previous failed attempts: navigate(), history.replaceState() (both caused re-renders).

### Triggers Declaration Order
tRPC query `triggersQuery` and derived `triggers` array must be declared BEFORE any useEffect that references them, otherwise ReferenceError occurs due to temporal dead zone.

### resetForm Must Use setMode("designer")
When creating a new form, resetForm sets mode to "designer" (not "form") so the user lands directly on the blank canvas, which is the expected UX flow.

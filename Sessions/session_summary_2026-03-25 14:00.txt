- Self-approval explicitly blocked (separation of duties)
- Allocation overflow detection (>100% across all active assignments)

- `server/workspace/__tests__/assignment-resolver.test.ts` — 10 test cases (contract, governance, lifecycle, conflict detection)

**Modified (2 files)**:
- `server/workspace/workspace-router.ts` — added `staffing` sub-router with query-only endpoints (resolve, pendingRequests)
- `server/workspace/shell-view-resolver.ts` — extended ShellView with staffing summary (assignmentCount, hasConflicts, bridgeConnected), added resolveStaffingSummary helper

**Key Design Decisions**:
- Workspace is READ-ONLY for staffing data — no write exports, no .mutation() endpoints
- Graceful fallback: returns empty view when DB unavailable or tables don't exist
- Links workspace to project via purposeRef or wizardMeta.anchorRef
- Default filter: only "pending" and "active" assignments (released/completed opt-in)

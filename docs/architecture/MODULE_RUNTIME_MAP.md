# Module Runtime Map

Per-module summary of runtime mode, owned database, and runtime
endpoints. Generated by hand from each module's manifest; if you
change a manifest's `runtime`, `database`, or `runtimePorts`, update
this table.

| Module | Runtime mode | Owned DB | Endpoints |
|---|---|---|---|
| Code Studio | worker | codedb | `opencode-runtime` (4096), `opencode-web` (4200–4299), `codedb` (postgres) |
| Agent Studio | worker | asdb | `asdb` (postgres) |
| Sandbox WF | worker | wfdb | `wfdb` (postgres) |
| PRM | embedded | prmdb | `prmdb` (postgres) |
| PSM | embedded | psmdb | `psmdb` (postgres) |
| PS | embedded | shared (appdb) | — |
| RAG | worker | ragdb | `ragdb` (postgres) |
| OpenRouter | embedded | shared (appdb) | — |
| KGRA Agent | embedded | shared via RAG | — |
| Documents | embedded | shared (appdb) | — |

Plus the platform-wide endpoints declared in
`server/platform/ports/default-declarations.ts`:

- `platform/http` (Express + Vite, port 3000)
- `platform/postgres` (host Postgres, 5432)
- `platform/ollama` (Ollama, 11434)

## Boot flow

1. `server/_core/index.ts` boots the Express app.
2. `getRuntimeManager().boot()` runs the port-conflict check, then
   walks modules in dependency order calling each manifest's `boot`
   hook.
3. After `server.listen()` succeeds, the main HTTP port is reserved
   in the registry (`platform/http`, `ownerRef: "main-server"`).
4. `getRuntimeManager().postListen()` runs each manifest's
   `postListen` hook.

## Per-module DB ownership

Each module-owned DB lives on the same Postgres instance as the
platform DB by default. Overrides via `DATABASE_URL_*` env vars (see
`RUNTIME_ENDPOINTS.md`) let operators split them out.

## Termux note

This repo's CLAUDE.md instructs Claude not to run builds, tests, or
dev servers on the device. The boot flow above is what CI exercises;
local Termux runs may diverge (notably OpenCode Web, which goes
through the proot-distro Ubuntu rootfs because Bun's listen syscall
fails under Termux's proot).
